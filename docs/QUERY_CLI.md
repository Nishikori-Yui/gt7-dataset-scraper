# Database Query CLI & API

[English](QUERY_CLI.md) | [简体中文](QUERY_CLI.zh-CN.md)

This document describes the `gt7_query` interface for reading the SQLite database.
It assumes the database was generated by `gt7_scraper` (see `DATASET_GENERATION.md`).

## CLI
Backend options (global):
- `--query-engine python|go` (default: `python`)
- `--query-go-bin ./local/bin/gt7-query-go`
- If Go backend fails or binary is missing, CLI prints a warning and falls back to Python backend.
- Current validated Go scope: `list` (except `max_power`/`weight`), `stats`, `overview`.
- `car` and `list --sort max_power|weight` intentionally fall back to Python backend.

### List cars (id + name)
```bash
python -m gt7_query list --db output/gt7.db --locale gb --sort manufacturer --limit 5
```

Sort options:
- `manufacturer`
- `country`
- `drivetrain`
- `max_power` (uses gb spec values, no unit conversion)
- `weight` (uses gb spec values, no unit conversion)

Notes:
- `--locale` controls localized output (`car_texts`, `manufacturer_i18n`, i18n labels) when available.
- Sorting by `max_power` and `weight` always uses `car_specs` for locale `gb` for comparability.
- Sorting by `country` prefers the country mapping tables; if missing, it falls back to `cars.raw_json` + mapping JSON.

Output formats:
- `--format json` (default)
- `--format text`
- `--out path/to/output.json`

Example (text output):
```bash
python -m gt7_query list --db output/gt7.db --locale cn --sort country --limit 20 --format text
```

### Get car details
```bash
python -m gt7_query car --db output/gt7.db --locale cn --car-id car31 --format json
```

Output fields:
- `id`, `name`
- `manufacturer` (localized name when available)
- `country` (`country_id`, `iso3`, localized name)
- `drivetrain` (code + label)
- `aspiration` (code + label)
- `intro`, `detail`
- `specs` (ordered by `sort_order`)
- `images` (hero + thumb if present)

Notes:
- If a localized `car_texts` row exists, `name/intro/detail` are taken from it; otherwise canonical values from `cars` are used.
- `specs` are read from `car_specs` for the requested locale and joined with `spec_code_i18n` for labels.

### Stats
```bash
python -m gt7_query stats --db output/gt7.db --locale gb --by country
```

Group options:
- `manufacturer`
- `country`
- `drivetrain`

### Overview
```bash
python -m gt7_query overview --db output/gt7.db
```

Go backend example:
```bash
python -m gt7_query --query-engine go --query-go-bin ./local/bin/gt7-query-go list --db output/gt7.db --locale gb --sort manufacturer --limit 5
```

## Python API

```python
from pathlib import Path
from gt7_query.queries import list_cars, get_car_details, stats_by_country

db = Path("output/gt7.db")

cars = list_cars(db, locale="gb", sort_by="manufacturer", limit=10)
car = get_car_details(db, "car31", locale="cn")
stats = stats_by_country(db, locale="gb")
```

## Sorting Notes
- `max_power` and `weight` use gb locale values from `car_specs` and are not converted.
- If country tables are missing, `list --sort country` falls back to `raw_json` + mapping JSON.

## Common Scenarios
- Generate a list sorted by power for quick comparisons.

- Aggregate counts by manufacturer or country for quality checks.
