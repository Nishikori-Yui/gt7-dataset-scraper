# 法律与发布指引

[English](LEGAL_AND_PUBLISHING.md) | [简体中文](LEGAL_AND_PUBLISHING.zh-CN.md)

本文提供一般性参考建议，**不构成法律意见**。运行爬虫前请自行阅读并遵守网站条款和适用法律。

## 核心原则
1. 遵守网站条款。
2. 不发布抓取的资产。
3. 代码与数据分离。
4. 避免产生官方背书印象。
5. 测试时尽量小规模访问。

## 发布检查清单
- 确保 `.gitignore` 排除 `output/` 与 `*.db`。
- 不提交任何抓取图片、Logo 或 JSON 原始数据。
- 仓库仅保留代码与文档。
- README 中加入法律提示。
- 若内部使用数据集，保留原始的版权/商标声明。

## 常见限制
多数网站条款会限制对内容的二次使用、数据库构建或资产再分发。若条款禁止，请勿在未获许可时继续。

## README 建议提示（短版）
- 本项目仅用于学习。
- 使用者需自行遵守网站条款与法律。
- 仓库不包含抓取数据或资产。
- 商标与版权归原权利人所有。

## 发布强化建议
- 示例命令默认加 `--skip-images`。
- 提供 `--car-list` 示例引导小范围抓取。
- Playwright 设为可选并清晰说明。
- 贡献指南中明确禁止提交数据和资产。
